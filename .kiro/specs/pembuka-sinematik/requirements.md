# Persyaratan pembuka Desa Kalisepi

| ID | Hasil yang dapat diperiksa |
| --- | --- |
| P1 | Kunjungan awal menampilkan layar hitam dengan identitas IndoGhost sebelum desa terlihat. Gerbang menampilkan kemajuan 00–100% berdasarkan kesiapan gambar dan font. |
| P2 | Tombol ENTER THE VILLAGE aktif saat aset siap. Pemain dapat memilih suara, melewati pembuka dengan tombol atau Escape, dan masuk saat aset gagal atau lambat. |
| P3 | Komposisi gerbang mengantar pemain ke adegan pertama. Gerak terbatas menghilangkan gerak kamera dan kabut. Keyboard bisa mengoperasikan seluruh kontrol. |
| P4 | Reload, navigasi bagian, dialog serta mode latihan tidak mengulang pembuka setelah masuk pada sesi tab tersebut. Sesi baru dapat memutar pembuka lagi. |
| P5 | Seluruh tujuh malam, preferensi suara, ekspor jurnal berkas, kontrol horor dan gameplay tetap lulus regresi. |
