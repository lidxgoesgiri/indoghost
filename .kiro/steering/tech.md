# Arsitektur dan pengujian

Gunakan React, TypeScript strict dan Vite untuk aplikasi. Phaser memiliki jam, input dan render Chase. Aturan deterministik dapat diuji terpisah dari GPU. Simpan kontrol puzzle dan ruangan sebagai elemen DOM yang bisa dioperasikan dengan keyboard.

Pakai GSAP dengan ScrollTrigger dan Lenis untuk cerita. Three.js melalui React Three Fiber menangani kamera dan layer 3D. Muat engine dan efek berat berdasarkan kebutuhan. Bersihkan seluruh loop/listener per instance. Uji save sebelum mengubah format, uji transaksi progres saat replay dan pisahkan progres latihan.
